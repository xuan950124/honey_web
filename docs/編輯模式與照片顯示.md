# 編輯模式與照片顯示

兩件事：一、報導和故事的照片不再被裁切；二、前台可以直接點著改東西。

---

## 一、照片不再被裁切

### 原本的問題

報導頁的照片被硬塞進 16:9 的框裡，超出的部分直接裁掉。
你上傳的那張「黃皇龍養蜂農場」照片是直式的拼貼圖，
所以上面的「養蜂農場」字被切掉一半，人的頭也被切到。

### 現在的做法

報導、故事、商品情境照都改成**不裁切**：

- 照原始比例顯示，**一個像素都不裁**
- 比內文寬的照片會縮到跟內文一樣寬 —— 左右剛好對齊，不會凸出去也不會內縮
- 直式的高照片最高只佔畫面高度的 78%（手機 62%），不會一張圖吃掉整個螢幕
- 比內文窄的小圖保持原尺寸置中，**不硬拉大**（拉大只會變模糊）

四種情況都是等比縮放，不會變形。

### 哪些地方還是會裁切

商品卡的縮圖（首頁精選、商品列表、團購）仍然是正方形裁切，這是刻意的 ——
那些圖要排成整齊的一排，如果每張高度都不一樣，整個版面會歪掉。

所以**商品主圖建議上傳正方形的**，其他地方的照片不用管比例。

## 二、編輯模式：在前台直接點著改

### 怎麼用

用工作人員帳號登入後，右下角會有兩顆按鈕：

| 按鈕 | 功能 |
|---|---|
| **編輯模式** | 打開後可以點前台的內容去修改 |
| 手機版預覽 | 以手機尺寸檢視這一頁 |

按下「編輯模式」之後：

1. 後台可以改的每一塊會浮出**虛線框**，滑過去變成實線加淡黃底
2. 點下去會跳出提示：「**這個區塊是 品牌標語．要現在去修改嗎？**」
3. 按「前往修改」→ 直接跳到後台那一頁，**自動捲到那一格並閃兩下**
4. 改完按「儲存全部設定」

按 **Esc** 可以關掉提示，再按一次退出編輯模式。底部工具列也有「關閉編輯模式」。

### 選單和連結照正常運作

編輯模式下**導覽列、購物車、麵包屑、手機版選單都還是正常的**，可以直接換頁。

這是刻意的 —— 如果連結也被攔住，你就得「關掉編輯模式 → 換頁 → 再打開」，
那這個功能沒人會想用。

### 點到不是可編輯的地方呢

也會有回應，只是講的是整頁：「**這一頁的內容是 商品列表．要現在去修改嗎？**」

有幾塊會老實告訴你改不了，例如首頁的「品牌四大特色」——
那四項目前寫在程式碼裡，提示會說「後台改不了，要調整請跟我說要換成哪四點」。
比讓你在後台找半天好。

### 目前可以點的區塊

| 頁面 | 可以點的地方 |
|---|---|
| 頁首 | 網站名稱、頁首標語、訂購專線 |
| 首頁 | 大標、說明文、主視覺照片、精選商品區、團購區、品牌故事區、消息區、四大特色 |
| 商品列表／首頁 | 每一張商品卡（直接跳到那個商品的編輯頁）|
| 商品內頁 | 整個商品區塊 |
| 新聞列表／內頁 | 每一則報導、標題、主圖 |
| 品牌故事 | 每一則故事 |
| 聯絡我們 | 電話、LINE、地址、Email、營業時間、溯源編號、社群、QR Code、地圖 |
| 頁尾 | 網站名稱、品牌介紹、溯源編號徽章、聯絡資訊 |

商品卡會直接連到**那一個商品**的編輯頁（`/admin/products/12`），不是商品列表，
少一次「在列表裡找」的功夫。

## 三、為什麼不做「直接在前台改字」

技術上做得到，但沒做，理由是：

- **會有兩套邏輯。** 後台的表單已經有欄位說明、格式檢查、儲存提示。
  前台再做一份，兩邊就會慢慢長得不一樣，改了一邊忘了另一邊
- **容易改到一半忘記存。** 沒有明確的「儲存」動作，很容易以為改好了其實沒有
- **權限與錯誤處理要重寫一次。** 每個小輸入框都要處理「存失敗了怎麼辦」

現在的做法是「**把你帶到正確的地方**」——
省掉的是「這個東西到底在後台哪裡改」這件事，那才是真正花時間的部分。
真正的儲存還是走後台那一份已經驗證過的表單。

---

## 四、技術上的兩個決定

### 用屬性，不包元件

可編輯區塊是靠一組 `data-*` 屬性標記的，不是包一層 `<EditWrapper>`：

```jsx
<span {...editable('品牌標語', '/admin/settings', 'shop_slogan')}>…</span>
```

包元件會多出一個 DOM 節點，在 grid / flex 版面裡很容易把排版弄壞。
用屬性的話，**關掉編輯模式時一般訪客看到的畫面跟以前一模一樣**，零影響。

點擊是在 document 上攔一個 capture 階段的 click，
用 `closest('[data-edit]')` 找出被點到的區塊 —— 所以不管標了幾個地方，
都只有一個事件監聽器。

### 高亮只閃一下就消失

從前台跳過來時，網址會帶 `?focus=shop_slogan`，後台捲到那一格、加金框、閃兩下，
**2.6 秒後高亮自動消失，網址上的參數也清掉**。

不永久留著是因為：高亮的目的是「告訴你是這一格」，看到了就該退場。
一直閃著的話，你接著改同一頁的其他欄位時會一直有東西在旁邊晃。
清掉網址參數則是為了重新整理不會又閃一次。
