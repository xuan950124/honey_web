# 綠界帳戶餘額與出貨

建立物流單時看到這一句：

> 訂單建立失敗(綠界帳戶可提領餘額為負數或不足支付物流運費無法建立訂單)

**這不是網站的錯，是綠界帳戶裡沒錢付運費。** 按幾次都一樣。

---

## 一、為什麼會這樣

超商店到店的運費是**你先付**的，不是等買家取貨才收：

```
你建立物流單  →  綠界從你的帳戶餘額扣運費（約 70 元）
                      ↓
              帳戶是 0 元 → 扣不到 → 建單失敗
```

新帳戶的餘額本來就是 0，所以第一次出貨一定會卡在這裡。

而且這是個先有雞還先有蛋的問題：**沒有餘額就不能出貨，不出貨就收不到貨到付款的錢**。
所以一定要先儲值一次，不能等。

---

## 二、你現在要做兩件事

### ☐ 1. 儲值

綠界廠商後台 → **綠界帳戶管理 → 預付款項**

一筆超商運費約 70 元。先存個一兩千塊，可以跑二三十單，之後貨到付款的錢
進來就會自己補上，不用一直儲值。

### ☐ 2. 關掉每日自動提領（重要）

你目前設定的是：

| 排程 | 金額 | 帳戶 |
|---|---|---|
| **每日** | 固定 300 元 | 中華郵政 |

**這個設定會讓你一直建不了單。** 錢一進帳就被領走，餘額永遠接近 0，
下一筆出貨又扣不到運費。

而且提領手續費是 **15 元／次**。每天領 300 元等於固定被抽 5%，
一個月光手續費就 450 元。

建議：

- **先把自動提領停用**，等出貨穩定、帳戶有一定餘額後再開
- 要開的話改成**每週或每月**，並把「設定金額」調高（例如保留 2,000 元在帳戶裡再提領超出的部分）
- 綠界後台有寫：綁**永豐銀行**帳戶可以免提領手續費。你如果有永豐帳戶，換過去一年省好幾千

---

## 三、網站這邊改了什麼

以前失敗只會顯示綠界那一句原文，你不知道要去哪裡按什麼 ——
所以你對著同一顆按鈕按了二十幾次（瀏覽器主控台整排 400）。

現在後台會直接把**處理步驟**排出來，並附上綠界後台的連結。
系統認得這幾種常見失敗：

| 綠界回的話 | 網站會告訴你 |
|---|---|
| 可提領餘額不足 | 去「預付款項」儲值，順便檢查自動提領設定 |
| 門市不存在／停業 | 聯絡買家改選門市或改宅配 |
| 金額超過上限 | 超商上限 20,000 元，改宅配或分兩筆 |
| CheckMacValue 錯誤 | HashKey／HashIV 貼錯，注意 0 與 O、1 與 I 和 l |
| 查無廠商編號 | 檢查環境變數，以及 `ECPAY_LOGISTICS_ENV` 有沒有設對 |
| 服務尚未開通 | 到「物流管理 → 修改物流型態」把超商與宅配勾起來 |

認不出來的錯誤會照原文顯示，並請你把那句話貼給我。

---

## 四、儲值之後的出貨流程

1. 後台「訂單與出貨管理」→ 展開訂單 → **建立物流單並取得寄件代碼**
2. 拿到**寄件代碼**（7-11 還會有驗證碼）
3. 包裹帶到超商，在機台輸入寄件代碼列印單據
4. 貼上單據交給店員，不用付錢（運費已經從你的綠界餘額扣了）
5. 買家取貨時付現（貨到付款），綠界代收後撥回你的帳戶

> 第一次建議自己下一筆單走完整個流程，包含到超商機台試印。
> 測試環境跟正式環境的機台操作有細微差異，走過一次心裡才踏實。

---

## 五、餘額要留多少

粗算：

```
每筆超商運費        約 70 元
貨到付款代收手續費   代收金額 × 0.75%（最低 3 元）
```

一天出 5 單大約需要 350 元的餘額週轉。**建議帳戶常態保留 2,000 元以上**，
週末或連假前多留一點（那幾天出貨多，撥款卻會順延）。

後台的「訂單管理 → 待出貨」數字乘以 70，大概就是你現在需要的餘額。
