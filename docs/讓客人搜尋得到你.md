# 讓客人搜尋得到你

先說結論：**網站的技術面已經做完了，接下來能拉開差距的都不是程式。**

Google 排名大致看三件事：

1. **這個網站在技術上讀得懂嗎** ← 已經做好
2. **這家店真的存在嗎** ← 你要去辦（第二節，**最重要**）
3. **這個網站有沒有人願意看** ← 要持續累積（第三、四節）

---

## 一、程式已經做好的（你不用管）

| 項目 | 作用 |
|---|---|
| `sitemap.xml` | 依實際商品自動產生，新增商品不用重做，下架商品自動排除 |
| `robots.txt` | 後台、購物車、訂單頁不給收錄（訂單網址帶存取碼，被收錄等於外流） |
| 每頁獨立的標題與描述 | 搜尋結果顯示的那兩行 |
| canonical | 帶追蹤參數的網址不會被當成不同頁面而分散權重 |
| **LocalBusiness** 結構化資料 | 店名、電話、地址、**座標**、營業時間、價格區間 |
| **Product** 結構化資料 | 商品頁的價格與庫存狀態，搜尋結果會直接顯示 |
| **FAQPage** 結構化資料 | 常見問題會被 Google **展開在搜尋結果裡**，版面大好幾倍 |
| OG／Twitter 標籤 | LINE、FB 分享時的預覽卡片（寫死在 `index.html`，因為它們不執行 JS） |

| **網站圖示** | 搜尋結果旁邊那個小圓圖，用後台上傳的 icon |

> 座標那一項對「基隆蜂蜜」這種在地查詢特別有用 ——
> Google 是拿地理位置在比對的，給它一段地址它還要自己猜。

### 關於搜尋結果的小圓圖

以前一直顯示預設的地球圖示，原因是 **Google 抓 favicon 只讀首頁的靜態 HTML、
不執行 JavaScript**，而且圖示必須跟首頁**同一個網域**。
前端載入後才用 JS 換成 `api.huanglong-honey.com/uploads/…` 的圖，兩個條件都不符合。

現在 `index.html` 直接寫同網域的 `/site-icon.png`，由 nginx 代理到後端，
內容是後台「網站設定 → 圖片 → 網站 icon」上傳的那張。

- **換圖不用重新部署**，網址永遠不變
- 分享到 LINE／FB 的大圖 `/og-cover.jpg` 同理，用的是首頁主視覺（實景照比 logo 好）
- Google 更新圖示要**幾天到幾週**，在 Search Console 用「網址審查 → 要求建立索引」可以催
- 圖示規格：**正方形**、建議 48×48 的倍數（你現在那張蜜蜂圖沒問題）

## 二、你要辦的（照順序做，這節最重要）

### ☐ 1. Google 商家檔案（免費，影響最大）

你已經有「皇龍養蜂場」的商家檔案了，但要把它**經營起來**：

- **補完資料**：營業時間、電話、**網站網址填 `huanglong-honey.com`**、服務項目
- **上傳照片**：蜂箱、採蜜過程、產品、環境。Google 明說照片多的商家點擊率高很多
- **每週發一則「最新動態」**：花期、採收、出貨公告 —— 30 秒的事，但商家檔案會被 Google 判定為活躍
- **想辦法拿評價**：老客戶取貨時直接請他掃碼給評價。**評價數是在地排名最重的因素之一**，你現在只有 1 則

> 為什麼商家檔案比網站重要：搜「基隆 蜂蜜」的人，
> 有一半以上根本沒往下滑到一般搜尋結果，他們點的是上面那個地圖區塊。

### ☐ 2. Google Search Console

1. `search.google.com/search-console` 新增資源
2. **兩個網域都要驗證**：`huanglong-honey.com` 與 `api.huanglong-honey.com`（DNS TXT）
3. 提交 sitemap：`https://api.huanglong-honey.com/sitemap.xml`
4. 用「網址審查」把首頁、商品頁各送一次「要求建立索引」

> 為什麼要兩個：sitemap 放在 API 網域、裡面列的是主網域的網址，
> 這在 Google 叫「跨網域提交」，兩邊都驗證過才生效。

**之後每個月打開看一次**「成效」報表：哪些字有人搜、點擊率多少。
那份報表會直接告訴你該寫什麼文章。

### ☐ 3. 收錄檢查

上線兩週後在 Google 搜 `site:huanglong-honey.com`。
搜不到任何結果 = 還沒被收錄，回 Search Console 看「網頁索引」有沒有錯誤。

## 三、你的關鍵字策略

**不要跟蜂蜜大廠拚「蜂蜜」這種字。** 那是幾百萬預算在打的戰場。

小蜂場能贏的是**具體、有意圖、競爭者少**的長尾字：

| 類型 | 例子 | 為什麼你贏得了 |
|---|---|---|
| **在地** | 基隆蜂蜜、七堵蜂蜜、基隆伴手禮、瑪陵坑 | 你真的在那裡，大廠不在 |
| **產地＋品項** | 基隆龍眼蜜、台灣野花蜜、國產百花蜜 | 進口蜜商搶不走 |
| **疑問** | 蜂蜜結晶正常嗎、真假蜂蜜怎麼分、蜂蜜可以放多久 | 已經做進 FAQ 了 |
| **用途** | 蜂蜜送禮推薦、公司團購蜂蜜、蜂蜜伴手禮 | 團購頁就在打這個 |
| **信任** | 溯源蜂蜜、有產銷履歷的蜂蜜、蜂農直售 | 你有溯源編號，大部分小農沒有 |

**做法**：把這些字自然寫進商品說明、故事、報導內文。
不要硬塞成「基隆蜂蜜基隆蜂蜜」那種 —— Google 認得出來，而且會扣分。

## 四、持續要做的事（照投報率排序）

### 1. 每則報導都寫完整內文（最省力、最有效）

你現在的新聞頁有真實的媒體報導，但**內文只有一兩句**。
Google 對「一頁只有 50 個字」的評價很低。

每則補到 300～500 字：報導的來龍去脈、當天發生什麼、記者問了什麼。
**這是你手上最容易產出、又最有說服力的內容。**

### 2. 商品說明寫長一點

現在每個商品大約兩句話。目標 300 字以上，寫這些：

- 這款蜜是什麼花期採的、什麼時候
- 顏色、香氣、甜度跟其他款差在哪
- 怎麼吃最好（沖水？拌優格？配什麼？）
- 誰適合買（送禮？自己吃？第一次買蜂蜜的人？）

> 順帶一提：**沒有照片的商品幾乎不會有人下單**，這比任何 SEO 都重要。

### 3. 把品牌故事寫成真的故事

「基隆一年下兩百天雨」這種句子很好 —— 具體、只有你講得出來、別人抄不走。
再多寫幾段：怎麼開始養蜂的、最慘的一年、為什麼堅持等熟成。

### 4. 每個月寫一篇「有人會搜的文章」

放在「最新消息」就好，不用另外做部落格。題目直接從第三節的疑問字來：

- 蜂蜜結晶了還能吃嗎？（附自己蜜結晶的照片）
- 怎麼分辨真蜂蜜與糖漿蜜？三個在家就能做的測試
- 龍眼蜜、百花蜜、荔枝蜜差在哪？
- 基隆的雨季怎麼影響蜂蜜產量
- 送禮該挑哪一款蜂蜜？

**一篇有照片的真實經驗文，勝過十篇拼湊的文章。**

### 5. 讓別人連結到你

外部連結是 Google 判斷「這個網站可信嗎」的主要依據。

- 媒體報導了你 → **請對方在文章裡放上網站連結**（很多人不會主動放）
- 農會、產銷班、基隆觀光網站的商家名錄 → 主動去登錄
- 合作的店家、市集 → 互相放連結
- 社群貼文附網址（社群連結本身權重低，但會帶真人流量）

### 6. 網站速度與手機版

已經做好了（圖片延遲載入、打包後 120 KB）。
Google 是用**手機版**排名的，右下角那顆「手機版預覽」可以隨時檢查。

## 五、不要做的事

| 不要 | 為什麼 |
|---|---|
| 買連結、買流量 | Google 抓得到，會被降權，救回來很痛苦 |
| 關鍵字硬塞 | 「基隆蜂蜜推薦基隆蜂蜜第一名」這種寫法會被判定為垃圾 |
| 抄別人的商品說明 | 重複內容不會有排名 |
| 期待一個月見效 | 新網站的觀察期通常 3～6 個月，這是正常的 |
| 為了 SEO 寫假內容 | FAQ 的答案如果頁面上找不到，結構化資料會被判違規 |

## 六、現實的時間表

| 時間 | 會發生什麼 |
|---|---|
| 第 1～2 週 | 開始被收錄，搜「黃家基蜜」找得到你 |
| 第 1～2 個月 | 品牌名穩定排第一，商家檔案開始有曝光 |
| 第 3～6 個月 | 長尾字（基隆蜂蜜、蜂蜜結晶…）開始進前幾頁 |
| 第 6 個月以後 | 有內容累積的話，流量會開始明顯成長 |

**這段期間最有效的事不是調 SEO，是把商家檔案經營好、把報導內文寫完。**

---

## 七、如果只能做三件事

1. **Google 商家檔案補完照片與資料，並開始收集評價**
2. **每則報導的內文補到 300 字以上**
3. **Search Console 提交 sitemap，每月看一次成效報表**

其他都可以之後再說。
