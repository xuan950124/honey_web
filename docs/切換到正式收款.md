# 切換到正式收款

綠界後台三項都顯示「已開通」之後，網站這邊還要改一次設定才會真的收得到錢。

> **網站不會自己知道你開通了。** 收不收得到錢是由後端的環境變數決定的，
> 綠界後台按了開通，網站這邊沒改就還是測試環境 —— 客人刷了你收不到。

---

## 一、要改的環境變數（Zeabur → 後端服務 → Variables）

### ☐ 1. 環境切成正式

```
ECPAY_ENV=production
```

原本是 `stage`。這一行是主開關。

`ECPAY_LOGISTICS_ENV` 之前設成 `production` 是為了「金流還在審核時先賣貨到付款」，
現在兩邊都開通了，**留著或刪掉都可以**（留著的效果一模一樣）。

### ☐ 2. 填自己的金流金鑰

```
ECPAY_MERCHANT_ID=<你的特店編號>
ECPAY_HASH_KEY=<你的 HashKey>
ECPAY_HASH_IV=<你的 HashIV>
```

到哪裡拿：綠界廠商後台 → **系統開發管理 → 系統介接設定**，
選「**正式環境**」那一組（不要拿測試環境的）。

> **這一步最容易漏，而且漏了比不切還糟。**
>
> 只改 `ECPAY_ENV` 不換金鑰的話，客人會被帶到**正式**的付款頁，
> 然後每一筆都因為檢查碼或廠商編號不符而失敗，
> 畫面上只有一句綠界的錯誤訊息，沒有人知道原因是什麼。
>
> 所以系統會自己認出「你還在用綠界的公開測試金鑰」並**維持線上付款關閉**，
> 後台的「付款方式」區塊會直接把這句話列出來。

貼的時候注意 `0` 與 `O`、`1` 與 `I` 和 `l`。HashKey 與 HashIV 都是 16 碼。

### ☐ 3. 確認回呼網址是 https

```
BACKEND_BASE_URL=https://api.huanglong-honey.com
```

綠界的付款結果只認伺服器對伺服器的通知，會打這個網址。
設錯的話**錢收到了、訂單卻不會變成已付款**。

### ☐ 4. 物流金鑰（如果還沒填）

```
ECPAY_C2C_MERCHANT_ID / ECPAY_C2C_HASH_KEY / ECPAY_C2C_HASH_IV     ← 超商店到店
ECPAY_HOME_MERCHANT_ID / ECPAY_HOME_HASH_KEY / ECPAY_HOME_HASH_IV  ← 宅配
```

正式環境這兩組通常跟金流是同一組，填一樣即可。

## 二、改完怎麼確認

改完等 Zeabur 重新部署，然後看兩個地方：

**後台 → 網站設定 → 付款方式**

- 綠色的「線上付款已開通」= 成功
- 紅色框 = 沒成功，框裡會直接寫是哪一項沒設好

**打開 <https://api.huanglong-honey.com/api/orders/checkout-options>**

```json
"ecpay_status": {
  "payment_production": true,
  "payment_credentials_ok": true,
  "can_sell_online": true,
  "warnings": []
}
```

`can_sell_online` 是 `true` 才算完成。`warnings` 有東西就照著改。

---

## 三、第一筆真的刷刷看

**用自己的信用卡買一件最便宜的商品**，走完整個流程。這一步不要跳過。

要確認的事：

1. 刷卡成功後，**訂單狀態有沒有變成「已付款」**
   （沒變 = 回呼網址不對，錢在綠界那邊但你的系統不知道）
2. 綠界後台 →「訂單查詢」看得到這一筆
3. 後台的訂單明細顯示的金額與你刷的一致

刷完可以在綠界後台退刷。手續費（2.75%）通常不退，當作學費。

---

## 四、要開放哪幾種付款方式

**後台 → 網站設定 → 付款方式**，勾起來的才會出現在結帳頁。

| 方式 | 費率／成本 | 適合 |
|---|---|---|
| 信用卡 | 2.75% | 大部分人；入帳最快 |
| ATM 虛擬帳號 | 每筆固定手續費 | 金額大的訂單划算，但買家會忘記轉帳 |
| 超商代碼繳費 | 每筆固定手續費 | 沒有網銀的買家；有金額上限 |
| 貨到付款 | 代收金額 × 0.75%（最低 3 元）| 第一次買、不敢先付錢的人 |

**建議全部開著。** 每多關一種就少一群買得下去的人，
而未使用的付款方式不會產生任何費用。

> 這一頁只能**再關掉**，不能打開綠界還沒開通的服務 ——
> 錢收不收得到是綠界那邊決定的，放一個開了也沒用的開關只會誤導。
>
> 系統一定會幫你保留貨到付款：一種都不能選的結帳頁等於關店。

---

## 五、切正式之後有什麼不一樣

| | 測試環境 | 正式環境 |
|---|---|---|
| 付款頁 | payment-stage.ecpay.com.tw | payment.ecpay.com.tw |
| 刷卡 | 用測試卡號，不會扣款 | **真的扣款** |
| 結帳頁 | 顯示測試卡號提示 | 不顯示 |
| 撥款 | 沒有 | 依綠界的撥款週期入帳 |

結帳頁那段測試卡號提示會自動消失（它看的是 `ecpay_status`，不是寫死的）。

> **測試卡號 `4311-9511-1111-1111` 在正式環境是無效的**，
> 不要拿它來驗證「有沒有切成功」—— 它一定會失敗，但那不代表設定錯了。
> 要驗證就用真的卡刷一筆最便宜的。
