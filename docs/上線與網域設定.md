# 上線與網域設定

## 先講結論：你家的網路不能用傳統的「開通訊埠」方式架站

從你提供的資訊看：

| 項目 | 你的值 | 意義 |
|---|---|---|
| 路由器 | TP-Link TL-MR6400（4G LTE 路由器）| 走行動網路上網 |
| **WAN IP** | **10.90.203.148** | ⚠️ **這是私有 IP** |
| IPv6 | 2402:7500:4dc:a327::/64 | 有真實的公網 IPv6 |
| 電腦 IP | 192.168.1.107 | 內網位址 |
| 路由器 LAN IP | 192.168.1.103 | |

**關鍵在 WAN IP 是 `10.90.203.148`。**

`10.x.x.x` 屬於 RFC1918 定義的私有網段。你的路由器對外那一端拿到的是私有 IP，
代表電信業者把你放在 **CGNAT（大型網路位址轉換）** 後面 —— 也就是很多用戶共用少數幾個真實 IP。

這造成一個硬限制：

> **就算你在路由器上設定通訊埠轉發（Port Forwarding），外面的人還是連不進來。**
> 因為連線在電信業者的那層 NAT 就被擋掉了，根本到不了你家路由器。

行動網路（4G/5G）幾乎都是這樣。這不是設定問題，是架構問題，改設定解決不了。

> 你確實有公網 IPv6，理論上 IPv6 可以直連。但實務上不建議：
> 電信業者通常也會擋 IPv6 的入站連線；而且**綠界的伺服器極可能只支援 IPv4**，
> 付款通知會打不進來。台灣也還有不少家用網路是純 IPv4，客人會連不到。

---

## 解法：分三個階段來

### 階段一：先在自己家的 Wi-Fi 測手機版（現在就能做）

這階段不用網域、不用設定任何東西，最適合你現在要優化手機 UI 的需求。

1. 手機連上**同一個 Wi-Fi**
2. 電腦上點兩下 **`手機測試網址.bat`**，會列出你的區域網路網址
3. 手機瀏覽器輸入 `http://192.168.1.107:5173`

前端已經設定成監聽區域網路，所以直接就能連。

**連不上的話**：第一次執行時 Windows 防火牆會跳出提示，要選「**允許存取**」。
如果不小心按到封鎖，到「Windows Defender 防火牆 → 允許應用程式」把 Node.js 和 Python 打勾。

> 這個階段只有你家 Wi-Fi 內的裝置連得到，外面的人看不到，很適合安心測試。

---

### 階段二：讓外面的人也能連（用 Cloudflare Tunnel）

**這是你這種 CGNAT 環境唯一實際可行的免費方案，也順便解決 ngrok 網址一直變的問題。**

原理是：你的電腦主動「向外」連到 Cloudflare，建立一條隧道。
因為是**出站連線**，完全不需要通訊埠轉發，CGNAT 擋不住。

#### 為什麼比 ngrok 好

| | ngrok 免費版 | Cloudflare Tunnel |
|---|---|---|
| 網址 | **每次重開都變** | 固定不變 |
| 自訂網域 | 付費才有 | 免費 |
| 瀏覽器警告頁 | 有 | 沒有 |
| HTTPS 憑證 | 有 | 有 |
| 費用 | 免費 | 免費 |

#### 設定步驟

**1. 先買一個網域**

Cloudflare Tunnel 要搭配自己的網域。推薦 [Cloudflare Registrar](https://www.cloudflare.com/products/registrar/)，
它用成本價賣不加價，`.com` 一年大約 US$10（約 NT$320）。

也可以選台灣的 `.tw` / `.com.tw`（[網路中文](https://www.net-chinese.com.tw/)、
[中華電信 HiNet](https://domain.hinet.net/) 等），一年約 NT$600~800。
`.tw` 對台灣客人的信任感較好，但價格較高。

> 網域名稱建議直接用店名，例如 `huanglonghoney.com`。

**2. 把網域交給 Cloudflare 管理**

在 Cloudflare 註冊免費帳號 → Add a site → 輸入你的網域 →
它會給你兩個 Name Server，回到你買網域的地方把 NS 改成那兩個（生效約幾十分鐘到幾小時）。

若直接在 Cloudflare Registrar 買，這步會自動完成。

**3. 安裝 cloudflared**

下載 Windows 版：<https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/>

**4. 建立隧道**

```bat
cloudflared tunnel login
cloudflared tunnel create honey
cloudflared tunnel route dns honey shop.你的網域.com
cloudflared tunnel route dns honey api.你的網域.com
```

**5. 設定要轉發到哪裡**

編輯 `C:\Users\a0920\.cloudflared\config.yml`：

```yaml
tunnel: honey
credentials-file: C:\Users\a0920\.cloudflared\<隧道ID>.json

ingress:
  - hostname: api.你的網域.com
    service: http://localhost:8000
  - hostname: shop.你的網域.com
    service: http://localhost:5173
  - service: http_status:404
```

**6. 啟動**

```bat
cloudflared tunnel run honey
```

**7. 改本專案的 `backend\.env`**

```ini
APP_ENV=production
BACKEND_BASE_URL=https://api.你的網域.com
FRONTEND_BASE_URL=https://shop.你的網域.com
CORS_ORIGINS=https://shop.你的網域.com
```

改完**重啟後端**。從此綠界的付款與物流通知都會穩定打得進來，不用再管 ngrok 換網址。

---

### 階段三：真的要營業的話，搬離家用 4G

用家裡的 4G 網路長期營業有幾個現實問題：

- **電腦關機或斷網，網站就掛了**
- **4G 上傳頻寬有限**，你的訊號強度只有 50%，客人載圖會慢
- **行動網路通常有流量上限**，超量會降速
- 停電、跳電就整個中斷

真的要開始賣，建議把後端搬到雲端主機。適合這個專案的：

| 平台 | 費用 | 特點 |
|---|---|---|
| **Railway** | 有免費額度，之後約 US$5/月起 | 最好上手，支援 Python + MySQL，推 git 就部署 |
| **Render** | 免費方案會休眠，付費 US$7/月起 | 介面單純 |
| **Fly.io** | 有免費額度 | 可選日本節點，對台灣延遲低 |
| **DigitalOcean / Linode** | US$6/月起 | 完整的 VPS，自由度高但要自己設定 |
| **GCP / AWS** | 有免費試用 | 功能最完整，但設定最複雜 |

前端（純靜態檔）可以直接放 **Cloudflare Pages** 或 **Vercel**，兩者都免費且快。

> 建議路線：先用階段一測手機版 → 階段二買網域接 Cloudflare Tunnel 給朋友試用、
> 順便把綠界流程跑順 → 確定要開賣再搬到雲端。

## 綠界的注意事項

不管哪個階段，綠界的回呼網址（`BACKEND_BASE_URL`）都必須：

- 是**外部連得到的公開網址**
- 走 **80 或 443 埠**（綠界只支援這兩個）
- 建議用 **HTTPS**

所以階段一（區域網路）測不了綠界的自動通知，這是正常的 —— 
可以用後台的「向綠界查詢付款狀態」手動補。
到階段二接上 Cloudflare Tunnel 之後就完全正常了。

## 常見問題

**Q：我可以直接用路由器的通訊埠轉發嗎**
不行。你的 WAN IP 是 `10.90.203.148` 這種私有位址，代表在 CGNAT 後面，
外部連線到不了你家路由器。這是電信業者的架構，設定改不了。

**Q：那我打電話跟電信業者要固定 IP 呢**
行動網路方案通常不提供，就算有也是加價的企業方案。
如果你家同時有**光世代／有線寬頻**，那條線通常有真實的公網 IP，可以用通訊埠轉發。
但即使如此，還是建議用 Cloudflare Tunnel —— 不用暴露自家 IP，也附帶免費 HTTPS。

**Q：一定要買網域嗎**
測試階段不用，階段一在區域網路就能測。
但要讓外面的人連、要接綠界正式環境、要客人記得住網址，還是需要一個網域。
一年三百多塊，是必要投資。

**Q：DDNS（動態網域）可以用嗎**
不行。DDNS 只是把「會變動的公網 IP」對應到固定網域，
但你根本沒有公網 IPv4，所以 DDNS 幫不上忙。TP-Link 內建的 DDNS 在 CGNAT 下也無效。

**Q：Cloudflare Tunnel 要一直開著嗎**
是的，`cloudflared` 和你的前後端都要保持執行。可以把它設成 Windows 服務開機自動啟動：
`cloudflared service install`。
